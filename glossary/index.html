Glossary

A–Z definitions for S-BOS terms, acronyms, frameworks, and role names.

Home → Glossary
ACD FIK MNO PSV W
A
Audit Stage
A stage marked in orange in the value chain. The Ops Manager must check file completeness before the team can proceed to the next stage. Audit stages are: File & Project Setup, Execute Diligence & Contingencies, and Pre-Closing.
C
Clarify and Verify
The mandatory check between every Supply and Receive step. Before passing work forward, confirm all details are accurate and complete. When in doubt, stop and confirm. This is non-negotiable at every stage of the value chain.
D
DISC
Behavioral assessment framework used to describe team member communication and work styles. Roles in the value chain are mapped to DISC profiles: Broker (Balanced), Ops Manager (High I/S), Production Manager (Mostly I), Practitioner (High I).
F
FUB
Follow Up Boss — the CRM used for client notes, action plans, and transaction tracking. The Practitioner and Production Manager are primary users during escrow. Post-closing action sets are also triggered and tracked in FUB.
I
IREN-MD
Information · Request · Emotions · Needs · Materials · Decisions/Deadlines — the framework used to structure every handoff in the value chain. When preparing to pass work to the next role, run through each element to ensure the handoff is complete.
K
Kompass
The MCP (Model Context Protocol) server that connects Claude to SmartSuite and Google APIs. Powers all Claude agents. When a team member triggers a Claude skill, Kompass routes Claude's requests to the correct SmartSuite apps, Google Drive folders, and other S-BOS data sources.
M
MCP
Model Context Protocol — the open standard that allows Claude to use tools and connect to external systems like SmartSuite. Kompass is the S-BOS MCP server implementation.
N
Nesting
The post-closing follow-up phase where the Practitioner executes the FUB post-closing action set and the Buyer receives continued support, tax documents, vendor lists, and anniversary reminders. Stage 09 in the value chain.
NORR
Notice of Repair Requirements — the formal document created when a buyer objects to diligence findings and requests changes to the property or transaction terms. Created during the Assemble & Respond stage.
O
Ops Manager
The internal team role responsible for compliance audits, master database management, and file approval. High I/S DISC profile, "Team Mom" archetype. Owns audit stages and final sign-off before closing.
P
Practitioner
The agent or team member who holds the client relationship and executes the transaction on behalf of the buyer or seller. High I DISC profile, "Document Bulldog" archetype — task-focused, compliance-oriented, strong attention to detail.
Production Manager
The internal client role responsible for escrow coordination, document tracking, and communication orchestration. Mostly I DISC profile, "Emotional Guide" archetype — fights for clients, solves problems, orchestrates all parties.
S
S-BOS
Stitser Business Operating System — the full integrated technology platform including SmartSuite, Softr, Google Drive, Smartsheet, Follow Up Boss, and Kompass. Not a single app, but an orchestrated stack designed to connect people, processes, data, and AI across all Stitser BUILT entities.
SmartSuite
The database layer of S-BOS. Stores all structured records: contacts, projects, transactions, tasks, pay apps, journals, and more. Team members access SmartSuite data through Softr — no SmartSuite seat required for most roles.
Smartsheet
Used exclusively for project construction schedules. One sheet per project, owned by Zach Roullier. Embedded in SmartSuite project records so the schedule is visible without leaving S-BOS.
Softr
The team-facing web portal for S-BOS. Christine, Andi, Mary, and all team members use Softr as their primary interface — no SmartSuite seat required. Softr surfaces exactly the views, forms, and dashboards each role needs to do their work.
V
Value Chain
The structured sequence of Supply → Clarify & Verify → Receive steps that maps every escrow stage. Each role adds value at their position in the chain. The nine stages run from File & Project Setup through Nesting.
W
Woohoo Call
The celebratory call made by the Practitioner at closing to deliver the new home to the buyer. Listed as a formal step in Stage 07 — Closing. Not optional.
