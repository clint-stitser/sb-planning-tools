The Model
How the Value Chain Works

Every escrow stage follows the same fundamental pattern: Supply → Clarify & Verify → Receive. One role does the work of their stage and hands it forward. The receiving role checks that everything is complete and accurate before accepting it. No stage is skipped. No handoff happens without Clarify & Verify.

"Value Added" means something specific here: each role contributes what only they can contribute at their position. The Practitioner manages the client relationship. The Production Manager orchestrates the parties. The Ops Manager ensures compliance. Skipping a role doesn't speed things up — it creates gaps that cost time later.

Three stages require a formal Ops Manager audit before the team can proceed: File & Project Setup, Execute Diligence, and Pre-Closing. These are marked with an orange Audit badge. The audit confirms the file is complete and the team is cleared to move forward. See Audit Stage in the glossary.

Some actions — contract addenda, timeline changes, problem solving, failed contract — can happen at any stage. They don't fit neatly into the linear flow and are handled as they arise, always with Clarify & Verify applied.

The Nine Escrow Stages
01 · Audit Required
File & Project Setup
Enter contract in Smartsheet, assemble docs in Drive, notify Production MGR, introduce Production MGR to Buyer and Partner Agent.
Practitioner → Production MGR → Ops MGR
02
Escrow Open
Open escrow, notify all parties, verify commissions, confirm contact info and communication methods.
Production MGR → Title / Lender / Partner Agent
03 · Audit Required
Execute Diligence & Contingencies
Request diligence documents, initiate contingency timelines, order inspections, confirm client strategy and timing.
Production MGR + Practitioner → All Parties
04
Assemble & Respond
Receive and deliver diligence documents, review with client, create NORR if needed, object and provide substantiation.
Production MGR → Practitioner → Buyer
05
Re-Inspections & Walkthrough
Confirm repairs complete, coordinate re-inspections and walkthroughs, review new docs, buyer approves or rejects.
Partner Agent → Production MGR → Practitioner
06 · Audit Required
Pre-Closing
Coordinate all closing parties, send commission instructions for signature, review settlement statement, compliance audit.
Production MGR → Practitioner → Broker → Ops MGR
07
Closing
Confirm funding and recording, coordinate home delivery, Woohoo call, update MLS, activate post-closing action set.
Practitioner → Production MGR → Ops MGR
08
Commission Distribution
Review compliance docs, verify commission accuracy, deposit commission checks, disburse and track.
Ops MGR → Broker → Accountant
09
Nesting
Execute FUB post-closing action set, deliver vendor list, send tax documents, set anniversary reminders.
Practitioner → Buyer
