Stage 06 — Value Chain

Pre-Closing

Coordinate all closing parties, send commission instructions, confirm settlement statement, and clear the Ops Manager compliance audit.

● Audit Required
← Re-Inspections Closing →
Home→Workflows→Pre-Closing
Supplies
Production Manager
  • Coordinate and confirm: Lender has required disclosures and CD ready
  • Coordinate and confirm: Partner Agent confirms home is ready for delivery
  • Coordinate and confirm: Escrow has signing schedule, settlement statement, and commission instructions
  • Send commission instructions to Practitioner and Broker for signature
  • Remind Practitioner to review settlement statement
  • Instruct Title on commission delivery method
Clarify & Verify
⇅
All parties confirmed, all docs signed, audit cleared before Closing proceeds
Receives
Practitioner
  • Review settlement statement for accuracy
  • Confirm all details with client
  • Review and initial commission instructions
Broker
  • Sign commission instructions
Ops Manager
  • Run compliance audit — confirm file is complete
  • Clear the transaction to proceed to Closing
AI Assist
Claude Can Help Here

The Compliance Auditor agent supports the Ops Manager audit at this stage. It fetches the transaction record, walks the linked Google Drive folder, and matches documents against the required disclosures checklist — flagging any missing or incomplete items before the audit is formally run.

Trigger Phrase
"Audit [property address]" or "Run the compliance audit"

What you still own: The formal audit sign-off, the judgment call on any flagged items, and the final clearance decision.

Outputs
Key Deliverables
  • Commission instructions signed by Practitioner and Broker
  • Settlement statement reviewed and confirmed accurate
  • All parties confirmed ready for closing day
  • Ops Manager audit complete — file cleared to close
