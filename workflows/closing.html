Stage 07 — Value Chain

Closing

Confirm funding and recording, coordinate home delivery, make the Woohoo call, and hand off to post-closing.

← Pre-Closing Commission Distribution →
Home→Workflows→Closing
Supplies
Practitioner
  • Confirm funding status with Lender
  • Confirm recording status with Escrow
  • Confirm closing docs delivered to client
  • Coordinate home delivery with Partner Agent
Partner Agent
  • Hand over keys, remotes, and lockbox
  • Remove sign from property
Clarify & Verify
⇅
Confirm recorded before keys are delivered — funding ≠ recorded
Receives
Practitioner
  • Deliver new home — keys, garage remotes, lockbox code
  • Do the final walkthrough with Buyer
  • Make the Woohoo call
  • Take celebratory photos
  • Update MLS to Sold status
Production Manager
  • Confirm MLS has been updated
  • Activate post-closing action set in FUB
Ops Manager
  • Update master database with closed transaction
  • Begin file audit for compliance
Outputs
Key Deliverables
  • Funding and recording confirmed — transaction is legally closed
  • Keys delivered to Buyer — home officially theirs
  • Woohoo call made — celebratory delivery complete
  • MLS updated to Sold with correct close price and date
  • Post-closing action set activated in FUB
  • Master database updated — Ops Manager file audit initiated
