Outputs
Key Deliverables
  • Smartsheet transaction record — contract entered, key dates set, parties populated
  • Google Drive client file — all initial documents assembled and organized
  • FUB client notes — action plan launched, key transaction info recorded
  • Required docs checklist — Production Manager's tracking list for the escrow
AI Assist
Claude Can Help Here

The Baseline Capture agent can be triggered immediately after contract execution to create the project baseline in SmartSuite. This is especially useful for construction, flip, and development projects where budget and timeline data needs to be captured upfront.

Trigger Phrase
"Baseline this project" or "New project"

What Claude does: Walks through conversational intake for budget line items, timeline, deal type, and key parties. Creates structured SmartSuite records.

What you still own: The strategic decisions about deal structure, the client relationship introduction, and confirming all documents are correctly assembled in Drive.
