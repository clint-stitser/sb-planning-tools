Underwriting Model

Full lifecycle deal analysis for Formation Homes — capital stack, pro forma, lot release P&L, and management reports.

Home→Agents→Underwriting Model
Capability
What This Agent Does

The Underwriting Model is a full lifecycle deal analysis agent built specifically for Formation Homes ground-up development projects. It models any scenario: land acquisition, construction budget, capital stack structure, phased lot releases, and projected returns — all in one conversational session.

The agent builds a pro forma from your inputs, runs the capital stack math (equity, debt, preferred returns), calculates lot release P&L at various price points, and generates management-ready summary reports. If numbers change, you adjust and re-run — Claude holds the full model context during the session.

What it reads: Your deal inputs (land cost, construction budget, lot count, timeline, capital stack terms, projected pricing).

What it creates: Pro forma model, capital stack analysis, lot release P&L scenarios, management summary report.

What it does NOT do: It does not replace market analysis, does not make the go/no-go decision, and does not commit capital. The model informs the decision — it doesn't make it.

Trigger
How to Trigger It
Primary
"Let's underwrite a deal"
Also Works
"Help me model this project" · "Run the underwriting model"

You can also lead with deal specifics: "I want to underwrite a 12-lot infill in Meridian — land is $800k." Claude will use what you provide and ask for the rest.

Process
What Happens Step by Step

  1. Claude asks for project overview — location, lot count, deal type (infill, subdivision, vertical).

  2. Claude collects cost inputs — land, horizontal construction, vertical per lot, soft costs, carry.

  3. Claude collects capital stack terms — equity, preferred return, debt structure, fees.

  4. Claude collects revenue assumptions — lot pricing, absorption timeline, release schedule.

  5. Claude builds the pro forma and capital stack model, then presents summary metrics: total cost, projected revenue, equity multiple, IRR.

  6. Claude generates lot release P&L for each phase and a management summary report.

  7. You can adjust any input and Claude reruns the affected calculations in real time.

Your Responsibility
What You Still Own
  • Market analysis and comp validation — the model is only as good as your pricing inputs
  • Capital stack negotiations and investor relationships
  • The go/no-go decision
  • Final report review before sharing with investors or partners
FAQ
Tips & Common Questions
Can I use it for a deal that's already in progress?
Yes — you can bring actuals and model forward from where you are. Tell Claude what's already spent vs. estimated, and it will model the remaining upside.
How do I run sensitivities?
Just ask: "What if land cost is $950k?" or "Show me the model at $485k/lot vs $520k/lot." Claude holds the full model context and reruns the math instantly.
Does it save to SmartSuite?
The agent generates the model output in-session. You can ask Claude to format it as a report you save separately. SmartSuite write integration for underwriting records is on the roadmap.
