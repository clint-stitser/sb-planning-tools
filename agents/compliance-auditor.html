Compliance Auditor

Audits a property contract against the required disclosures checklist, links Drive files, and creates SmartSuite tasks for every finding.

Home→Agents→Compliance Auditor
Capability
What This Agent Does

The Compliance Auditor reads the SmartSuite transaction record for a specific property, walks the linked Google Drive folder, and matches the documents on file against the required disclosures checklist for that transaction type. It flags any missing, incomplete, or unsigned items and creates a SmartSuite task for each finding so nothing falls through the cracks.

The agent also checks that key fields in the SmartSuite record are populated correctly — commission amounts, party contact info, key dates — and surfaces any gaps before the Ops Manager runs the formal audit. This means the audit conversation starts from a prepared state, not a cold one.

What it reads: SmartSuite transaction record, linked Google Drive folder and documents, required disclosures checklist for the transaction type.

What it creates: SmartSuite tasks for each finding, a summary audit report for the Ops Manager's review.

What it does NOT do: It does not make the final compliance determination. It does not sign off on the audit. It does not decide whether a flagged item is a blocker. Those are always the Ops Manager's calls.

Trigger
How to Trigger It
Primary Trigger
"Audit [property address]"
Also Works
"Run the compliance audit" or "Run the audit on [property]"

Claude will confirm which transaction you mean if the address matches multiple records. You can also say the client's last name: "Audit the Johnson transaction."

Process
What Happens Step by Step

  1. Claude fetches the transaction record from SmartSuite using the property address or client name you provided.

  2. Claude identifies the transaction type and loads the corresponding required disclosures checklist.

  3. Claude walks the linked Google Drive folder and checks each required document against the checklist.

  4. Claude checks SmartSuite record fields — commissions, parties, dates — for completeness.

  5. Claude creates a SmartSuite task for each missing, unsigned, or incomplete item.

  6. Claude presents a summary to you: items cleared, items flagged, and any record gaps found.

Value Chain
Where It Fits

This agent is most commonly triggered at Stage 06 — Pre-Closing as part of the Ops Manager compliance audit before clearing the transaction to close. It can also be run at Stage 01 — File & Project Setup to confirm the opening file is complete.

Your Responsibility
What You Still Own
  • The formal audit sign-off — Claude prepares, you certify
  • The judgment call on flagged items — whether each is a blocker or can proceed
  • Any follow-up conversations with parties to resolve findings
  • The decision to clear the transaction to close
FAQ
Tips & Common Questions
What if the property address matches multiple records?
Claude will ask you to confirm which transaction. You can provide the client name, escrow number, or close date to disambiguate.
Can I run it before the Pre-Closing stage?
Yes — running it at File Setup to confirm the opening file is a great habit. Catching gaps early is always better than finding them at Pre-Closing.
Will Claude resolve the findings itself?
No. Claude creates tasks for each finding but does not send emails, request documents from third parties, or make any changes to the file. That action is yours.
