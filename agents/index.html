How to Use Claude

Claude is accessed at claude.ai or through the Claude desktop app. You trigger skills by saying the right phrase — Claude reads the skill instructions and executes the workflow. You don't need to explain the context or describe what you want step-by-step. The right trigger phrase is all it takes.

The core principle: Claude handles the system tasks. You handle the judgment calls and client relationships. Claude will fetch records from SmartSuite, walk through checklists, create tasks, generate documents, and flag what needs attention. What it won't do is make the call about whether to proceed — that's always yours.

Every agent listed below has a detail page with the exact trigger phrases, a step-by-step breakdown of what Claude does, and a clear list of what you still own. When in doubt, read the agent detail page before triggering.
