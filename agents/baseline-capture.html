Baseline Capture

Conversational intake for project budget and timeline — any deal type. Creates structured S-BOS records in SmartSuite.

Home→Agents→Baseline Capture
Capability
What This Agent Does

Baseline Capture is a conversational intake agent that walks you through capturing the budget and timeline data for any Stitser BUILT project. It handles construction, flip, development, fractional, and TI deals — each with the right budget categories and timeline milestones for that deal type.

The conversation is one question at a time. Claude asks for the address, deal type, purchase price, and then walks through the budget line items appropriate for that project. At the end, it writes all the structured records back to SmartSuite — so the project is properly "in S-BOS" with a real baseline from day one.

What it reads: Existing SmartSuite project records (to avoid duplicates), deal type templates for budget categories.

What it creates: SmartSuite project record, baseline budget line items, key milestone dates.

What it does NOT do: It does not make deal decisions, evaluate feasibility, or set strategy. Those are always yours.

Trigger
How to Trigger It
Primary
"Baseline this project"
Also Works
"New project" · "Set up [address]" · "Get a project into S-BOS"

You can also lead with the address: "Let's baseline 123 Main Street — it's a flip." Claude will pick up the deal type and skip that question.

Process
What Happens Step by Step

  1. Claude asks for the project address and deal type (construction, flip, development, fractional, or TI).

  2. Claude confirms the deal type and loads the appropriate budget template and milestone structure.

  3. Claude walks through budget line items conversationally — one category at a time, asking for your numbers.

  4. Claude asks for key timeline dates — start, major milestones, target completion.

  5. Claude summarizes the baseline and asks you to confirm before writing anything.

  6. On confirmation, Claude writes the SmartSuite project record, budget lines, and milestone dates.

Value Chain
Where It Fits

Baseline Capture is triggered at Stage 01 — File & Project Setup, immediately after contract execution for construction and development projects. It ensures every project enters S-BOS with a real budget and timeline from day one — not a blank record filled in later.

FAQ
Tips & Common Questions
What if I don't have all the numbers yet?
You can say "unknown" or give a range. Claude will note it as TBD in the record. Better to have a partial baseline than no baseline — you can update it as numbers firm up.
Can I use it for a deal that's already in SmartSuite?
Yes — Claude will find the existing record and update it rather than creating a duplicate. Tell Claude the project name or address and it will locate and update the right record.
Which deal types does it support?
Construction, flip, development (ground-up), fractional, and tenant improvement (TI). Each has a different budget template. If your deal doesn't fit neatly, say so and Claude will ask clarifying questions to find the right fit.
