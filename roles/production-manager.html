Role Guide · Mostly I — DISC Profile

Production Manager

"Emotional Guide" — orchestrates all parties, fights for clients, solves problems, and keeps every escrow moving forward.

Home→Roles→Production Manager
Profile
Core Competencies
  • Party orchestration — coordinates Title, Lender, Partner Agent, and clients across all stages
  • Document tracking — owns the required docs checklist and follows every item to completion
  • Communication management — the central hub for all escrow communication
  • Problem solving — when things go sideways, Production Manager finds the path forward
  • FUB mastery — action plans, contact notes, and transaction tracking all live here
  • Pre-closing coordination — brings every thread together before the Ops Manager audit
Value Chain
Stage-by-Stage Responsibilities
Stage 01
File & Project Setup — Receives
Add key notes to FUB, launch action plan, set up transaction calendar and required docs list.
Stage 02
Escrow Open — Supplies
Open escrow, notify all parties, verify commissions, confirm contact info and communication methods for everyone.
Stage 03
Execute Diligence — Supplies
Audit required docs, send document requests to all parties, initiate contingency timelines, track incoming docs.
Stage 04
Assemble & Respond — Supplies
Receive all docs from parties, update Smartsheet, alert Practitioner with context on each incoming document.
Stage 06
Pre-Closing — Supplies
Coordinate all closing parties, send commission instructions, remind Practitioner to review settlement statement, instruct Title on commission delivery.
Stage 07
Closing — Receives
Confirm MLS is updated, activate post-closing action set in FUB.
Tools
Tools You Own
  • Follow Up Boss (FUB) — the Production Manager's primary workspace: action plans, contact notes, transaction tracking
  • Smartsheet — document tracking updates throughout escrow
  • Google Drive — document receipt and filing per signature requirements
  • Softr / SmartSuite — transaction record updates, required docs checklist
