Role Guide · High I — DISC Profile

Practitioner

"Document Bulldog" — task-focused, compliance-oriented, strong attention to detail. Holds the client relationship and executes the transaction.

Home→Roles→Practitioner
Profile
Core Competencies
  • Client relationship management — the Buyer's primary point of contact throughout the transaction
  • Document compliance — knows what's required, when, and ensures it's on file
  • Transaction execution — contract to close, every step touched and accounted for
  • Inspection coordination — vendor selection, timing, client strategy, re-inspections
  • NORR creation and substantiation — knows how to frame buyer objections in writing
  • Post-closing followthrough — Nesting action set, vendor list, anniversary reminders
Value Chain
Stage-by-Stage Responsibilities
Stage 01
File & Project Setup — Supplies
Enter contract in Smartsheet, assemble Drive file, notify Production Manager, introduce Production Manager to Buyer and Partner Agent.
Stage 03
Execute Diligence — Supplies
Confirm client strategy and inspection timing, select and order inspectors, confirm utilities on, coordinate payment.
Stage 04
Assemble & Respond — Receives & Supplies
Receive docs from Production Manager, review with client, create and send NORR, provide written substantiation for objections.
Stage 05
Re-Inspections — Receives
Review repair docs with client, coordinate and execute re-inspections and final walkthrough, add reports to file.
Stage 06
Pre-Closing — Receives
Review settlement statement, confirm details with client, review and initial commission instructions.
Stage 07
Closing — Supplies & Receives
Confirm funding and recording, coordinate home delivery, deliver keys, make the Woohoo call, update MLS.
Stage 09
Nesting — Supplies
Execute FUB post-closing action set, deliver vendor list, send tax documents, set anniversary reminders.
Tools
Tools You Own
  • Smartsheet — enter contracts and key dates at File Setup
  • Google Drive — assemble and maintain the client file
  • Follow Up Boss (FUB) — client notes, communication log, post-closing action set
  • Authentisign — signature routing for NORRs and client documents
  • MLS — update listing status at closing
Claude
Working with Claude in This Role

As a Practitioner, your most relevant Claude agents are Baseline Capture (at File Setup, for BUILT projects) and the Stitser Way Rituals (daily alignment practice). The Compliance Auditor is primarily the Ops Manager's tool, but you can run it to pre-check your own file before audit.
