Role Guide · High I/S — DISC Profile

Ops Manager

"Team Mom" — compliance-oriented, people-oriented, systems thinker. Owns the audit stages and the master database.

Home→Roles→Ops Manager
Profile
Core Competencies
  • Compliance audits — owns all three audit stages and is the final gatekeeper before each proceeds
  • Master database management — keeps the SmartSuite master database current and accurate
  • Commission distribution oversight — reviews docs, confirms accuracy before disbursement
  • File audit at closing — ensures every closed transaction has a complete, compliant file
  • System integrity — if something's wrong in S-BOS, Ops Manager finds it and fixes it
  • Team support — the person the team turns to when they're stuck in the system
Value Chain
Stage-by-Stage Responsibilities
Stage 01 ★
File Setup — Receives / Audit
Link Smartsheet to Master DB. Run audit to confirm opening file is complete before escrow opens.
Stage 03 ★
Execute Diligence — Audit
Review document requests and file status. Confirm diligence is properly initiated before contingencies run.
Stage 06 ★
Pre-Closing — Receives / Audit
Run full compliance audit. Confirm all required disclosures are on file, signed, and complete. Clear the transaction to close.
Stage 07
Closing — Receives
Update master database with closed transaction. Begin post-closing file audit.
Stage 08
Commission Distribution — Supplies
Review all compliance docs in the closed file. Confirm E&O insurance is current. Prepare for Broker sign-off.
★ Audit stages — Ops Manager must clear before team proceeds
Tools
Tools You Own
  • SmartSuite Master Database — the source of truth for all entities; Ops Manager keeps it current
  • Softr — primary interface for dashboards, audits, and transaction oversight
  • Google Drive — file audit at closing; confirms every document is on file
  • Smartsheet (read) — reviews project schedules linked in SmartSuite records
Claude
Working with Claude in This Role

The Compliance Auditor is your primary agent — trigger it before every Pre-Closing audit to get a prepared state before you run the formal review. It surfaces gaps so your audit conversation starts from a position of knowledge, not discovery.
