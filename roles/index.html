The Team
Four Roles in the Value Chain

Every position in the S-BOS value chain is held by one of four defined roles. Each role has a DISC profile, core competencies, and a specific set of stages where they Supply and Receive. Knowing your role means knowing exactly where you add value — and where to hand off.

High I · DISC Profile
Practitioner
"Document Bulldog"
Holds the client relationship and executes the transaction. Task-focused, compliance-oriented, strong attention to detail. Owns File Setup, Inspections, Re-Inspections, Closing, and Nesting.

Mostly I · DISC Profile
Production Manager
"Emotional Guide"
Orchestrates all parties in escrow. Fights for clients, solves problems, keeps everything moving. Owns Escrow Open, Diligence, Assemble & Respond, and Pre-Closing coordination.
View Role Guide →
High I/S · DISC Profile
Ops Manager
"Team Mom"
Compliance-oriented, people-oriented, systems thinker. Owns all three audit stages, master database management, commission distribution oversight, and file approval.
View Role Guide →
Balanced · DISC Profile
Broker
"Spreadsheet Guru"
Compliance knowledge, financial oversight, and team leadership. Signs commission instructions, verifies commission accuracy, and holds final legal responsibility for every transaction.
